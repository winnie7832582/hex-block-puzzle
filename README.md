# 六角積木拼圖（Hex Block Puzzle）

一個在瀏覽器中玩的六角格連接式積木拼圖模擬器，包含 120 關、即時連線檢查、提示與自動求解。

> **非官方作品**：本專案與任何商標擁有者無關，也不包含任何原廠題目、手冊內容或商標素材。積木配色與關卡皆為本專案自行設計或程式生成。

## 開始使用

直接用瀏覽器開啟 `index.html` 即可，不需要安裝任何東西。

## 操作方式

- **放置**：從右側拖曳積木到棋盤，或先點積木再點格子。
- **旋轉**：按 `R` 向右轉 60°，按 `Shift+R` 向左轉；滑鼠滾輪也可以旋轉。
- **翻面**：按 `F`。
- **取消**：按 `Esc` 把積木放回去。點棋盤上的積木可以拿起來重放。
- **提示**：提示會幫你放一塊正確的積木，或指出放錯的積木。
- **自動求解**：由瀏覽器內的求解器算出完整解答。

## 過關條件

12 塊積木全部放上棋盤，並且彼此扣成同一串。同一格最多兩個節點，只能是「實心球放進別塊積木的開口環」，且球的連桿必須對準環的缺口。

使用提示或自動求解的關卡不計入過關紀錄。

## 規則版本與已知限制

- **翻面**：目前版本允許積木翻面。依據我們使用的積木定義，只旋轉不翻面時，12 塊無法全部放進棋盤。這代表**積木定義可能與實體積木不符**，尚待確認。
- **粉紅積木（P12）**：幾何定義與題目資料的觀察結果不一致，尚未經實體確認。
- **關卡**：120 關由程式隨機產生，每關經求解器確認只有一個解。預先放好的積木數量各關不同，但盤面不是任何實體產品的題目。

如果你有實體積木的正確形狀，歡迎開 issue 提供，我們會修正定義並重新產生關卡。

## 專案結構

```
index.html                  單檔版模擬器（引擎、關卡、介面皆已內嵌）
src/engine.js               引擎：座標、擺法、盤面驗證、求解器
data/pieces.json            12 塊積木的節點定義（座標、連桿、缺口）
data/pieces.txt             同上，供 C++ 生成器讀取
data/levels.json            120 關：預放積木數與完整解答
tools/generate_levels.cpp   關卡生成器（隨機解 → 逐步移除積木直到唯一解）
```

### 重新生成關卡

```bash
g++ -O2 -o tools/generate_levels tools/generate_levels.cpp
# 參數：種子 輸出檔 解的搜尋上限 移除時的搜尋上限 最少保留塊數(0=不限)
# 需要一個 targets.txt：每行或以空白分隔，列出每關要預放的積木數
./tools/generate_levels 2026 levels.txt 20000 2000000 0
```

`targets.txt` 不隨專案提供，請自行定義每關的預放塊數。
